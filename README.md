# 📌 L’ultima lanterna

Gioco di ruolo narrativo single-player ambientato nelle miniere di Moria,
nell'universo del Signore degli Anelli. La struttura è composta da scene collegate, 
introdotte da una descrizione e con possibili scelte, quali oggetti da raccogliere,
scene secondarie da esplorare e combattimenti necessari per procedere con la storia.


---

## 🚀 Come eseguire il progetto

### Prerequisiti

- JDK 25

Gradle Wrapper è incluso al suo interno e le dipendenze JavaFX sono dichiarate 
nella configurazione Gradle.

### Scaricare il progetto

```bash
git clone https://github.com/simox180/GDR_Project.git
cd GDR_Project
```

### Build e test

```powershell
.\gradlew.bat build
```

### Esecuzione

```powershell
.\gradlew.bat :app:run
```

## 🤖 Uso di strumenti di AI

#### ChatGPT

1) Come contenitore di scelte progettuali/contesto dell'intero progetto, garantendo
   uniformità e regolarità delle decisioni, tramite l'utilizzo della funzione 
   Progetto.


2) Per valutare approcci architetturali più idonei al progetto


3) Supporto al debugging e analisi di possibili errori progettuali, casi limite o
   in mancanza dei dovuti controlli dei parametri


4)  Per ricevere suggerimenti sul layout e sulla disposizione grafica

#### Gemini Nano Banana 2

1) Generatore delle immagini del menù e delle scene

#### Codex

1) Generatore di Test JUnit


2) Generatore dei JavaDoc più semplici e ripetitivi
